Array methods used in this app

filter()
Search by text, genre and status; also used to delete a book.
includes()
Checks if the title or author contains the search text.
some()
Matches title OR author, and blocks duplicate titles.
sort()
Sorts the results by title, year or price (on a copy).
map()
Builds the table rows and the genre dropdown.
reduce()
Adds up the total value of all books.
find()
Finds the selected book when you click Edit.
findIndex()
Finds the position of the book to update.
every()
Checks that all form fields are filled in.
Set
Counts unique genres.
